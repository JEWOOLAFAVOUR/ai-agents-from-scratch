# AI Agents From Scratch

Hi, welcome pals, this repo is for you if you want to learn how to build AI agents from scratch. I’m learning this myself, so I’ll be documenting what I learn along the way, breaking down the concepts and building things as we go.

The goal is simple: understand how AI agents actually work, not just how to use a framework. We’ll start from the fundamentals and gradually build our way up to more advanced agentic systems.
